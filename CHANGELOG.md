# Changelog

All notable changes to the MoonPhase Plus project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-11-27

### Added
-[**Major Enhancement**] Complete overhaul of original moonphase calculator
-[**Multiple Versions**] Created 8 different versions for various use cases
-[**Visualizations**] Added ASCII art, charts, timeline displays
-[**Formats**] Multiple output formats: simple, detailed, JSON, HTML
-[**GUI Support**] Tkinter-based graphical interfaces
-[**Web Output**] HTML report generation with SVG visualizations
-[**Predictions**] Future moon event calculations
-[**Calendar Feature**] Monthly moon phase calendar generator
-[**Color Output**] Color-coded terminal output (where supported)

### Changed
-[**Complete Rewrite**] Re-implemented core calculation engine
-[**Enhanced Accuracy**] Improved illumination calculation precision
-[**Better UX**] More intuitive command-line interface
-[**Modular Architecture**] Separated calculation logic from presentation
-[**Error Handling**] Improved date parsing and error messages

### Technical
-[**Python 3.8+**] Modern Python support
-[**Package Structure**] Added setup.py and pyproject.toml
-[**Dependency Management**] Optional dependencies for advanced features
-[**Type Hints**] Added Python type hints throughout codebase
-[**Documentation**] Comprehensive README and user guides

## [1.0.0] - Original

Original moonphase.py tool by mlm128
- Basic moon phase calculation
- Simple ASCII art output
- Single date input format
- Minimal dependencies

## Migration from v1 to v2

Users of the original moonphase.py can:

1. **Drop-in replacement**: Use `moonphase_final.py` for enhanced features
2. **Backward compatibility**: All original functionality maintained
3. **Enhanced features**: New formats and visualizations available
4. **Multiple interfaces**: Choose from console, GUI, or web versions
